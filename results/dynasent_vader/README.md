# DynaSent VADER baseline

Zero-shot rule-based reference. VADER's three-way polarity is mapped heuristically to DynaSent's four classes; `mixed` is assigned when both positive and negative lexical evidence are sufficiently high. This mapping is a project-specific heuristic, not a canonical VADER output. The baseline has no labeled training budget and should be shown as a horizontal reference, not as a learned learning curve.
